# JW2026-WIN7-01 路网监测终端应急

> 练习靶：Win7 SP1 x64（`192.168.0.14`）  
> 赛制对标：个人赛「安全防护赛」+ 团队赛「人工智能综合防御赛」主机侧  
> 对象前缀：全部 `ctfir-marker`（实验室红线）；赛场不会有此外缀  
> 植入/清理：`tests/practice/jw2026_win7_01_install.cmd` / `jw2026_win7_01_cleanup.cmd`

## 背景

某省交通运输厅路网运行监测终端（Windows 7 Ultimate SP1 x64，工作组）出现异常外连与陌生计划任务。你以应急小组运维账号登录，完成**后门清除**和**基线加固识别**。平台按检查点判定，不收 Flag。

本题只覆盖主机侧（账户 / 持久化 / 文件 / 端口转发 / 等保基线）。本机没有 IIS / phpstudy / MySQL，Web 与数据库日志题放在后续套题。

## 运维约束（违反即视为业务中断）

1. 禁止关闭、改端口、改密码：`Administrator`、OpenSSH（`sshd`，当前 `22`）。
2. 禁止停 VMware Tools 相关服务与 Run 项。
3. 禁止清空事件日志（`wevtutil cl`）。
4. 机上 `CTF-Test-A7C9` 用户、Run 值、hosts 行 `ctf-test-a7c9.invalid`、目录 `C:\CTF-Test-20261108-A7C9`、任务 `CTF-Test-A7C9` 是**旧实验夹具**，不计入本套得分，不要删。
5. 后门配置必须**删除**，注释或改名不算过。
6. 本套实验对象一律带 `ctfir-marker`；清理脚本只动这些对象。

## 检查点（第一阶段：应急清除）

| 编号 | 考察点 | 指南对应 | 提示 |
|---|---|---|---|
| W1 | 后门账户 | 基线/账户治理 | 存在以 `$` 结尾、且在管理员组中的自建账户，登录界面被藏 |
| W2 | Guest 提权 | 权限收敛 | 内置 Guest 被启用并加入管理员组 |
| W3 | 启动项后门 | 应急响应 | HKLM Run 含解释器/下载特征 |
| W4 | 计划任务后门 | 应急响应 | 非 Microsoft 任务，动作含 certutil/http，以 SYSTEM 跑 |
| W5 | 服务后门 | 应急响应 | 伪装更新服务，binPath 落在可写目录 |
| W6 | 映像劫持 | 应急响应 | IFEO Debugger；实验机进程名带前缀（赛场常见 sethc/utilman） |
| W7 | 登录脚本 | 应急响应 | Winlogon 登录脚本被写入 |
| W8 | hosts 劫持 | 应急响应 | 交通业务风格域名被指到外部地址（只删本套那一行） |
| W9 | 端口转发 | 横向/维持 | netsh portproxy 把高位端口转到本机 3389 |
| W10 | 落地文件 | 应急响应 | Temp 可执行、桌面双扩展名、ADS 隐藏流、Startup 脚本 |
| W11 | 异常共享 | 横向 | 非默认共享 |
| W12 | UAC 被关 | 系统加固 | EnableLUA=0 |
| W13 | 空口令可网络登录 | 系统加固 | LimitBlankPasswordUse=0 |

建议顺序：账户 → 启动/任务/服务/IFEO → hosts/portproxy/共享 → 文件 → 加固项。每点改完再 `ctfir scan` 对照，不要一次改完再猜。

## 检查点（第二阶段：识别，本套不要求改）

下列是这台实验机**原本就有**的弱基线，写入报告即可。现在改会动到以后测试的对照环境。

| 编号 | 考察点 | 现状（2026-11-12 实测） |
|---|---|---|
| B1 | 密码策略 | 最小长度 0，历史 None，最长 Unlimited |
| B2 | 账户锁定 | Lockout threshold = Never |
| B3 | 主机防火墙 | 专用配置文件 State=OFF |
| B4 | 审核策略 | Process Creation / 部分 Logon 子类 = No Auditing |
| B5 | 默认管理共享 | C$ / ADMIN$ 在；AutoShareWks 未显式关闭 |

赛场同类项通常要改：`net accounts /minpwlen:8 /lockoutthreshold:5`、开防火墙（先放行 SSH/RDP/业务端口）、`auditpol /set`、`AutoShareWks=0` 后重启 Server 服务。

## 附录 B · 本机权限结论（出题环境）

SSH `Administrator@192.168.0.14` 实测（2026-11-12）：

| 项 | 结果 |
|---|---|
| 账户 | 内置 RID-500 `Administrator`，工作组，High 完整性 |
| UAC | EnableLUA 原值=1；`FilterAdministratorToken=0`（RID-500 远程不降权） |
| 令牌 | SeDebug / SeBackup / SeRestore / SeTakeOwnership / SeSecurity 均 Enabled |
| OpenSSH | `sshd` 以 LocalSystem 运行 |
| 植入能力 | 建用户/服务/SYSTEM 计划任务、写 HKLM、覆盖 System32、读 Security 日志、portproxy、共享：全部成功 |
| Admin 做不到 | `reg query HKLM\SAM` / `HKLM\SECURITY` → Access denied |
| SYSTEM | `schtasks /create /ru SYSTEM` 即可临时代跑；SYSTEM 能读 SAM 用户名列表。无 psexec |

结论：出本题不需要常驻 SYSTEM。ctfir 0.6.1 以 `privilege=admin` 扫描，本套 13 个植入点全部命中（70 条 findings，含 A7C9 旧夹具与机上原弱基线）。
